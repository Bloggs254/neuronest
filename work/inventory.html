A clearer view
of your stock.

Stockroom is a browser-based inventory tool for checking products, recording stock changes and keeping a movement history. You can try sample data or save your own records on this device.

The problem
we’re working on.

When product records and stock updates live in different places, even a simple question can take time: what do we actually have available?

This project explores bringing those everyday tasks into one workspace, so a business can check its products, record stock arriving or leaving, and see which items need a closer look.

What you can
do with it.

Search products, filter low stock, add or edit product details and record stock coming in or going out. Each movement keeps its date and the before-and-after quantity.

The tool checks quantities before accepting a movement and prevents stock from going below zero. Saved workspaces survive a reload in the same browser. JSON backups can restore your records; CSV exports let you use them in a spreadsheet.

A useful tool,
with clear limits.

This edition is built for one browser and one active workspace tab. It has no cloud account, shared access or encrypted storage. Clearing browser data can remove saved records, so keeping a downloaded backup matters.

A shared business deployment would need a secure backend, user permissions, managed backups and testing with the team that will use it. This browser edition does not claim to provide those services.
