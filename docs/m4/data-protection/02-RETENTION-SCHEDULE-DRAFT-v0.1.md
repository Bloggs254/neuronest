# Retention schedule — draft v0.1

Not approved for production. Proposed states are accepted, queued, delivered and failed, each with a request ID and timestamps. Message content must not appear in operational logs. The owner must approve separate retention periods for unsuccessful inquiries, active sales conversations, declined work, contracts and security logs. Automated deletion must preserve any documented legal hold. Backups need a compatible expiry process; deleting the live record alone is not full deletion. No period is adopted by this draft.
