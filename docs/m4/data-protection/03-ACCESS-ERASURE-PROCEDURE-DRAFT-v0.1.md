# Access and erasure procedure — draft v0.1

Not operational. A request would be received only through a verified monitored channel. Before disclosure or deletion, the responder must verify identity without requesting unnecessary identification. Search would cover the inquiry store, delivery system, correspondence and applicable backups. Record the request, decision, systems checked and completion date without copying the underlying message into logs. Explain any lawful refusal or backup delay. No public deletion endpoint is planned for Phase 1.
